# Local readiness inventory

`readiness.diagnostic(database=None, source_ids=(), environment=None, clock=None)` performs a read-only local inventory. It never connects to providers, prints environment values, executes LEAN, installs dependencies, migrates databases or changes permissions. An injected environment replaces the complete host environment, including runtime PATH discovery.

The report exposes only presence booleans for `ALPACA_PAPER_API_KEY`, `ALPACA_PAPER_SECRET_KEY` and `SEC_USER_AGENT`. Presence does not validate key syntax, identity, contact details, authentication or entitlement. Runtime detection checks an explicitly configured `LEAN_EXECUTABLE`, or searches an explicitly available PATH for `lean`; it does not establish that the executable is QuantConnect LEAN or verify its version. An invalid explicit executable does not fall back to another executable.

An optional existing SQLite database is opened with URI `mode=ro`, `query_only` and one read transaction. Only caller-selected source IDs are inspected. The inventory reports their declared origin and latest permissions at the operational clock, plus source-scoped counts in known price, calendar and SEC capture tables. A later current revocation takes precedence over older grants. Counts include staged or quarantined captures and are not content/hash validation, publication coverage or admission. Missing or malformed schemas fail closed without creating a database or returning a partial inventory.

Price/calendar blockers cover credential presence, explicit current source permissions, route and scope review, publication and coverage. SEC blockers cover identified contact configuration, source/CIK selection and acceptance-versus-publication limits. Export and LEAN remain blocked on a verified admitted slice and runtime/baseline validation. Reports always retain `credentials_verified=false`, `real_admission_verified=false`, `training_ready=false` and `live_trading=false`. These conservative flags express what this inventory can establish; it never certifies absence or presence of real admission by counting review rows.

`readiness_demo(directory)` writes repeatable missing/configured examples using invented presence-only environment entries. Both examples perform zero network requests and never claim that credentials or account access were verified. No configured value is written to the report. Source permissions remain declarations requiring independent review.
